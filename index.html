Greenhouse Gauge

Temperature & humidity gauge. Install the software in one click.

  1. Wire it up first (wiring guide).
  2. Plug the D1 Mini into this computer with a USB data cable.
  3. Click Install, pick the board from the list (USB Serial, CH340 or usbserial) and click Connect.
  4. When it's done, it asks for your Wi-Fi. Enter it, or skip: the gauge works without Wi-Fi.
This browser can't install it. Open this page on a computer in Chrome or Edge.
(Phones, Safari and Firefox don't work.)
This page must be opened over https. Use the link from the video.
The board isn't in the list? Swap the USB cable (most are charge-only), try another USB port, or install the free CH340 driver from the chip maker, WCH (needed on Windows and older Macs), then reload this page.
